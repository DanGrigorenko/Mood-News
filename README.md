# Mood News

Читалка реальных новостей в разных эмоциональных регистрах. Факты неизменны,
меняется только тон. Смысл проекта — в [`CONTEXT.md`](./CONTEXT.md) и
[`docs/adr/`](./docs/adr/).

Сервер тянет реальные новости из RSS-лент (Ingest) и переписывает их под
выбранный Mood через LLM, сохраняя факты. Читатель выбирает Mood в выпуске и по
клику на новость попадает на её страницу, где оригинал и переписанная версия
стоят рядом — со ссылкой на источник и результатом Fact Check.

Интерфейс сделан как нотная партитура: настроение — это указание исполнения над
строкой, оригинал и переписанное — два стана, соединённых акколадой, а Fact
Check рисуется нотами и паузами.

## Откуда берутся новости

Ingest забирает Article из русскоязычных RSS-лент (Lenta.ru, РИА Новости,
ТАСС, Коммерсантъ — список в `server/src/ingest.ts`). Сохраняется ровно то,
что отдала лента — заголовок и анонс (Snippet); по ссылкам за полным текстом
не ходим ([ADR 0004](./docs/adr/0004-snippet-only-no-page-scraping.md)).

Ingest запускается автоматически при старте, если база пуста, и повторно —
кнопкой «Обновить» на странице. Дедупликация по ссылке: повторный Ingest уже
известной публикации ничего не добавляет. Падение одной ленты не роняет
остальные.

## Хранение

SQLite файлом (`node:sqlite`, без ORM и миграций). Схема создаётся одним
`CREATE TABLE IF NOT EXISTS` при старте, ссылка — PRIMARY KEY (на нём и держится
дедупликация). Путь к файлу — `DB_PATH` (по умолчанию `server/mood-news.db`);
данные переживают перезапуск сервера.

SQLite, а не Postgres, выбран намеренно: проверяющему не нужно поднимать docker
или сервер БД — база это один файл, который создаётся сам при первом запуске.

## Переписывание тона (Rewrite)

`GET /api/articles/:id?mood=X` (где `:id` — `encodeURIComponent` ссылки Article)
возвращает переписанные заголовок и тело плюс результат Fact Check: список
Anchor, их число, список Missing Anchor и число попыток. `GET /api/moods` отдаёт
пять доступных Mood (`neutral`, `joyful`, `sad`, `ironic`, `dramatic`) с
человеческими названиями. Произвольный Mood отклоняется, а не уходит в модель.

Пара «Article + Mood» — первичный ключ таблицы `rewrites`: генерация ленивая,
кэш вечный ([ADR 0001](./docs/adr/0001-lazy-rewrites-cached-forever.md)). Первый
запрос пары медленный (вызов модели), повторный читается из базы и переживает
перезапуск.

### Как контролируются факты

Из Snippet механически, до всякой модели, извлекаются Anchor — числа, даты,
суммы, цитаты и имена ([ADR 0002](./docs/adr/0002-deterministic-anchor-fact-check.md)).
Промпт кладёт их явным списком, требует сохранить дословно и писать числа
цифрами, а не прописью. После генерации Fact Check сверяет присутствие каждого
Anchor в объединении заголовка и тела. При потере — ретрай с названием
потерянного, до двух раз. Если потеря осталась, Rewrite всё равно отдаётся с
непустым списком потерянного — провал показывается, а не прячется
([ADR 0003](./docs/adr/0003-failed-fact-check-is-shown-not-hidden.md)).

Сверка детерминированная (сравнение подстрок), а не через модель-судью: судья
сам может галлюцинировать, стоит денег на каждую проверку и даёт разный ответ на
один вход. Регулярки и `String.includes` — воспроизводимы, бесплатны и
проверяются юнит-тестами без сети и без ключа.

#### Пример сработавшего ретрая

Реальная новость Коммерсанта (Ingest 2026-08-16). Модель в драматичном регистре
в первой попытке теряет число `56` («десятки пожарных»), Fact Check это ловит и
называет потерю в промпте, вторая попытка возвращает `56` — Rewrite проходит:

```
Article: https://www.kommersant.ru/doc/8890654
Anchor (8): «56», «14», «Wildberries», «Подольске», «WB», «Григорий», «Артамонов», «Telegram»

попытка 1:
  заголовок: Огненный ад под Подольском: склад Wildberries (WB) охвачен пламенем
  Fact Check: потеряно «56» → ретрай
попытка 2 (промпт требует вернуть потерянное):
  заголовок: Огненный ад под Подольском: 56 пожарных бьются со стихией на складе Wildberries (WB)
  Fact Check: все Anchor на месте → успех

Итог: attempts=2, anchorCount=8, missing=[]
```

Прогон воспроизводится командой `node .sandcastle/retry-demo.ts`. Цикл
`generateRewrite`, извлечение Anchor и Fact Check — настоящие
(`server/src/{rewrite,anchor}.ts`); ответы модели в этом прогоне заскриптованы,
чтобы потеря Anchor случилась детерминированно (живая модель теряет их редко и
непредсказуемо).

### Что использовали из AI (модель и конфигурация)

AI используется ровно в одном месте — переписывание тона в `Rewrite`: текст
Snippet отдаётся LLM (по умолчанию `glm-4.7-flash` от z.ai) с промптом, который
задаёт эмоциональный регистр и жёсткие правила сохранности фактов. Извлечение
Anchor, Fact Check, Ingest и хранение — обычный детерминированный код без
модели. Проверено на живом z.ai; ключ бесплатный (см. [`.env.example`](./.env.example)).

Обращение к модели — по OpenAI-совместимому HTTP. Три переменные в `.env`
(`LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`) переключают z.ai/GLM, OpenRouter или
Groq. Сервер читает `.env` из корня встроенным флагом Node
`--env-file-if-exists=../.env` — без пакета dotenv. Шаблон — [`.env.example`](./.env.example).

**Без `LLM_API_KEY`** эндпоинт работает на заглушке: Snippet отдаётся
механически, помечен `stub: true` и не попадает в кэш — с появлением ключа
генерация происходит по-настоящему. Заглушка не трогает факты, поэтому проходит
Fact Check.

## Структура

Два независимых пакета без workspaces, оркестрация — через `concurrently`:

- `server/` — HTTP API на [Hono](https://hono.dev). Предъявляется как отдельный
  сервис, не завязанный на фронт.
- `web/` — React + TypeScript на [Vite](https://vitejs.dev). Запросы к `/api`
  Vite проксирует на сервер, поэтому в коде фронта нет абсолютных URL с портом.

## Запуск

```bash
npm install   # ставит и корень, и оба пакета (server, web)
npm run dev    # поднимает сервер (:8787) и фронт (:5173) одной командой
```

Открой http://localhost:5173 — в выпуске без единого клика появятся реальные
новости (при первом старте сервер дожидается Ingest, это несколько секунд).
У каждой новости свой адрес (`?n=<ссылка Article>`), так что на неё можно дать
прямую ссылку.

## Проверки

Каждый тикет обязан прогнать их перед коммитом:

```bash
npm run typecheck   # tsc --noEmit в обоих пакетах
npm test            # node:test в обоих пакетах (без Vitest/Jest)
```
