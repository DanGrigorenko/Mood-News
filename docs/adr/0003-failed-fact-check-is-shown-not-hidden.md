# Провалившийся Fact Check показывается читателю

Если после ретраев остались Missing Anchor, Rewrite всё равно отдаётся — вместе
со списком потерянного. Не 500, не молчаливый откат на Snippet.

Провал проверки здесь не сбой системы, а результат измерения: он доказывает, что
Fact Check реально работает. Спрятать его — значит выдать непроверенный текст за
проверенный.
