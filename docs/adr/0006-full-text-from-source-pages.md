# Snippet — полный текст со страницы источника, а не анонс из ленты

Ingest забирает полный текст статьи со страницы публикации и хранит его как
Snippet. Новость, чей полный текст достать не удалось, в базу не попадает —
огрызков быть не должно ни при каких условиях. Фильтр пустого анонса
([issue #7](../agents/issue-tracker.md)) становится частным случаем более
строгого правила «нет полного текста — нет новости».

## Это пересмотр ADR-0004, а не его отмена

В [ADR 0004](./0004-snippet-only-no-page-scraping.md) заход на страницу был
отклонён: анонса якобы достаточно, а парсинг упирается в пейволлы и
антибот-заглушки. Наблюдение про антибот верно, но вывод был обобщён на все
источники — а проверка (2026-08-16) показала, что закрыты только два из шести:

| Источник | Страница статьи |
|---|---|
| Коммерсантъ | текст берётся, абзацы `<p class="doc__text">` |
| РИА Новости | текст берётся, блоки `<div class="article__text">` |
| Интерфакс | текст берётся, абзацы `<p>` внутри `<article itemprop="articleBody">` |
| ТАСС | JS-капча Servicepipe, вместо статьи заглушка ~1.5 КБ |
| Lenta.ru | редирект на заглушку ~1.7 КБ |
| РБК | 401 |

Ни одна лента не отдаёт полный текст (ни `content:encoded`, ни длинный
`description`), так что заход на страницу неизбежен. Отсюда новый список
источников — **Коммерсантъ, РИА Новости, Интерфакс**; ТАСС и Lenta.ru убраны, их
страницы закрыты. Обходить защиту headless-браузером не нужно: трёх лент хватает
на сотни новостей в день.

ADR-0004 остаётся верным описанием того, почему нельзя парсить страницу
readability-парсером вслепую. Он не переписан: его вывод сужается до закрытых
источников, а не отменяется.

## Последствия

- **Одно узкое правило извлечения на источник.** Универсального разбора не
  существует: общий проход по абзацам тащит рекламу, меню и навигацию
  (проверено). Каждый источник парсится по адресному контейнеру своей вёрстки
  (`server/src/article-text.ts`). Новый источник — новое правило.
- **Нет текста — нет новости.** Если правило не сработало (заглушка, чужая
  разметка) или текст подозрительно короткий, новость пропускается, а не
  сохраняется наполовину. Сбой на одной новости или источнике не роняет Ingest —
  остальные сохраняются.
- **Ingest стал дольше.** Было три запроса к лентам — стало плюс один запрос на
  каждую новость. Стартовый Ingest сообщает ход работы (`onProgress`), чтобы не
  выглядеть зависшим.
- **Извлечение проверяется без сети.** Правила — чистые функции над сохранённым
  HTML: тесты (`server/test/article-text.test.ts`) гоняют образцы разметки
  каждого источника без сети и без ключа.
